# Screenshots de Experimentos

Esta carpeta contiene las capturas de pantalla de cada experimento para documentación visual.

## Nomenclatura

Usar el siguiente formato para nombrar los archivos:

```
[ID_PRUEBA]_[TIPO]_[DESCRIPCION].png
```

### Ejemplos:
- `T-001_panel_comparativo.png` - Panel 2×2 completo
- `T-001_dog_filter.png` - Solo ventana del filtro DoG
- `T-001_resultado_final.png` - Solo ventana de detección
- `T-005_analisis_detallado.png` - Zoom de una región específica

## Tipos de Screenshots Recomendados

### Por Cada Experimento (Mínimo):
1. **Panel Comparativo 2×2** - Vista completa del pipeline
2. **Filtro DoG** - Para evaluar calidad del filtro

### Opcionales:
3. **Resultado Final con estadísticas** - Versión con cuadro de stats
4. **Regiones problemáticas** - Zoom de falsos positivos/negativos
5. **Comparación lado a lado** - Antes/después de ajuste de parámetros

## Checklist de Captura

- [ ] Capturar ANTES de cerrar las ventanas
- [ ] Usar Win+Shift+S (Recorte de Windows)
- [ ] Incluir TODO el panel (no recortar información)
- [ ] Guardar inmediatamente con nombre correcto
- [ ] Referenciar en bitácora_experimentos.csv

## Uso en la Tesis

Estas imágenes serán fundamentales para:
- **Resultados (BM5):** Mostrar visualmente la evolución del algoritmo
- **Anexos:** Evidencia de pruebas realizadas
- **Presentaciones:** Material gráfico para defensa

## Tamaño de Archivo

- Formato recomendado: PNG (sin pérdida)
- Resolución: Nativa de pantalla (no redimensionar)
- Si el archivo es muy grande (>5MB), usar JPG con calidad 90%
