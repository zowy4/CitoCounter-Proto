# DOC-68-04: Restricciones de Uso y Distribución CITO-68

**Fecha:** 2026-10-02  
**Autor:** Zoé Andrés Chacón Zavala  
**Estado:** Aprobado  

## 9. Política de Acceso

| Rol | Acceso | Condiciones |
|-----|--------|-------------|
| **Investigador / Desarrollador** | Acceso completo | Uso en entornos de laboratorio o investigación. Debe aceptar advertencia "no diagnóstico". |
| **Citotecnólogo** | Visualización y análisis | Debe leer y aceptar advertencia "no diagnóstico" antes de ver resultados. |
| **Estudiante / Aprendiz** | Visualización educativa | Debe estar supervisado por citotecnólogo o investigador. Debe aceptar advertencia. |
| **Público en general** | **No autorizado** | El software no está dirigido al público general. |

## 10. Términos de Distribución

| Término | Descripción |
|---------|-------------|
| **Licencia** | Código abierto (ver LICENSE en repositorio). Uso no comercial para fines de investigación. |
| **Distribución** | Solo con documentación completa (CITO-68 y entregables asociados). |
| **Modificación** | Permitido con atribución. Cualquier modificación debe mantener advertencia "no diagnóstico". |
| **Citación requerida** | "CitoCounter-Proto v1.1, prototipo de investigación, no dispositivo médico. https://github.com/zowy4/CitoCounter-Proto" |
| **No distribuir** | No distribuir como herramienta de diagnóstico médico ni en contextos clínicos. |

## 11. Límites de Imágenes por Usuario

| Límetro | Valor | Justificación |
|---------|-------|---------------|
| **Imágenes por sesión** | Sin límite técnico, pero recomendado máximo 50 imágenes por usuario | Evitar sobrecarga de sistema y asegurar calidad de análisis |
| **Tamaño total por usuario** | Máximo 10 MB de imágenes procesadas por sesión | Límites OWASP/STRIDE para evitar Denial of Service |
| **Retención de datos** | Datos temporales en sesión, limpiados al cerrar | Cumplimiento LFPDPPP, no se persisten imágenes en servidor |

## 12. Prohibiciones

| Prohibición | Descripción |
|-------------|-------------|
| **Uso médico** | No usar para diagnóstico médico, toma de decisiones clínicas ni derivación de pacientes |
| **Representación errónea** | No representar el software como herramienta de diagnóstico ni dispositivo médico |
| **Modificación de avisos** | No remover o modificar las advertencias "no diagnóstico" incluidas en el software |
| **Distribución sin documentación** | No distribuir el software sin el documento CITO-68 y avisos asociados |
| **Uso comercial sin licencia** | No usar para fines comerciales sin adquirir licencia apropiada |

## 13. Requisitos de Citación

Al citar o referenciar CitoCounter-Proto, incluir:

```
CitoCounter-Proto v1.1
Prototipo de investigación para detección y clasificación de núcleos en citología cervical
No es software de diagnóstico ni dispositivo médico
Requiere revisión experta antes de cualquier conclusión
https://github.com/zowy4/CitoCounter-Proto
```
