# Contributing to CitoCounter Proto

¡Gracias por tu interés en contribuir a CitoCounter Proto!

## 🔬 Sobre el Proyecto

Este es un **prototipo de investigación científica** para análisis automatizado de células mediante el algoritmo Diferencia de Gaussiana (DoG). Está siendo desarrollado como parte de un proyecto de tesis académica.

## 🤝 Cómo Contribuir

### Reportar Bugs
1. Verifica que el bug no haya sido reportado antes
2. Crea un Issue describiendo:
   - Pasos para reproducir
   - Comportamiento esperado vs. observado
   - Versión de Python y librerías (ejecuta `py verificar_entorno.py`)
   - Screenshots si es relevante

### Sugerir Mejoras
1. Crea un Issue con la etiqueta "enhancement"
2. Describe claramente la mejora propuesta
3. Explica por qué sería útil para la investigación científica

### Contribuir Código

#### 1. Fork el proyecto
#### 2. Crea una rama para tu feature
```bash
git checkout -b feature/mi-mejora
```

#### 3. Realiza tus cambios siguiendo estos lineamientos:

**Estilo de Código:**
- Sigue PEP 8
- Documenta todas las funciones con docstrings
- Incluye comentarios explicativos en lógica compleja
- Mantén el estilo científico del código existente

**Commits:**
- Mensajes claros en español
- Un commit por cambio lógico
- Formato: `[Módulo] Descripción breve`
  - Ejemplo: `[dog_filter] Optimización del cálculo de sigmas`

#### 4. Prueba tus cambios
```bash
py verificar_entorno.py
py main.py
```

#### 5. Envía un Pull Request

## 📋 Áreas de Contribución

### Prioritarias:
- 🐛 Corrección de bugs
- 📊 Mejoras en visualización
- 🧪 Validación con datasets públicos
- 📖 Mejoras en documentación

### Bienvenidas:
- ⚡ Optimizaciones de rendimiento
- 🎨 Nuevos métodos de visualización
- 🔬 Implementación de otros algoritmos de detección
- 🌐 Traducciones a otros idiomas

### Requieren Discusión Previa:
- Cambios arquitectónicos mayores
- Nuevas dependencias
- Modificaciones al algoritmo DoG central

## 📜 Código de Conducta

- Respeto y profesionalismo en todas las interacciones
- Enfoque en la validez científica
- Reconocimiento de que este es un proyecto de investigación

## 🎓 Reconocimientos

Las contribuciones significativas serán reconocidas en:
- CONTRIBUTORS.md
- Documentación del proyecto
- Posibles publicaciones académicas derivadas

## ⚠️ Nota Importante

Este proyecto es parte de una investigación académica. Las contribuciones pueden ser citadas en la tesis final y publicaciones científicas futuras.

## 📧 Contacto

Para preguntas sobre contribuciones, abre un Issue o contacta al equipo de investigación.
